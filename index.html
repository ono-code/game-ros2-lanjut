Persiapan Locale Ubuntu Server

Sebelum memasang ROS 2 di Ubuntu Server, kita harus memastikan sistem mendukung encode karakter UTF-8. Jika locale tidak dikonfigurasi, ROS 2 bisa mengalami error komunikasi data!

Analogi Teknik Elektronika:

Sederhananya, Locale itu seperti menyamakan Baud Rate dan Protokol Bahasa pada komunikasi Serial RS232 / UART. Jika bahasa sistem berbeda, data sensor bisa corrupt!

Tugas Praktikum Kamu:

Eksekusi perintah setup locale di terminal sebelah kanan.

ubuntu@agv-industrial-server:~
SSH Active (Port 22)
Welcome to Ubuntu 22.04.3 LTS (GNU/Linux 5.15.0-88-generic x86_64)
System architecture: ARM64 / x86_64 Industrial Board
Type or click command buttons below to configure ROS 2.
----------------------------------------------------
ubuntu@agv:~$
